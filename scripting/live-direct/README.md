# Live Direct · Scripting 版

在 iPhone / iPad 的 [Scripting](https://apps.apple.com/app/scripting/id6479691128) App 里使用 Live Direct：控制面板、关注列表、一键跳转 APTV 等外部播放器，或直接在 Scripting 里看。

脚本只是 Live Direct 服务端的客户端：解析直播地址仍由你部署的服务完成，脚本不包含任何平台签名逻辑，也不保存平台 Cookie。

## 功能

- **频道列表**：读取私密订阅（M3U），按平台分组显示正在直播的频道，支持搜索、按平台筛选、下拉刷新。
- **关注列表**：左滑频道或长按选“关注”，关注的主播置顶显示；下播后仍保留在列表里（灰色），开播后自动回到“在播”。关注列表只存本机，可长按调整顺序。
- **播放**：
  - 外部播放器：APTV / VLC / Infuse / 自定义 URL Scheme。传给播放器的是服务端固定地址，每次打开都会重新解析并 302 到平台 CDN。
  - 内置播放器：系统 `AVPlayer`（支持画中画、锁屏控制）。iOS 系统播放器不支持 FLV，所以脚本会请求服务端新增的 `/s/令牌/hls/平台/房间` 地址拿 HLS 流。
- **服务器管理**（可选，需管理员令牌）：查看各平台状态和频道数、触发刷新、按平台添加/删除长期关注的主播（即服务端的“手动房间”/抖音分享链接），首次添加时可顺便启用该平台。

## 安装

1. 在 Scripting 里新建一个脚本（例如叫 `Live Direct`），把本目录的 `index.tsx`、`api.ts`、`store.ts`、`player.tsx`、`settings-page.tsx`、`server-page.tsx` 放进去（`script.json` 可选）。也可以用 `scripting-cli` 同步整个目录。
2. 运行脚本，按提示粘贴后台“订阅”里的私密订阅地址：`https://你的地址/s/订阅令牌/interface.m3u`。如果剪贴板里已有订阅地址，会自动填入。
3. 可选：右上角 `…` → 设置 → 填写管理员令牌，就能在“服务器与主播管理”里添加主播。

订阅链接和管理员令牌只存在本机钥匙串（Keychain），不进 Storage、不写日志。

## 播放方式与限制

| 平台 | 外部播放器 | 内置播放器 |
| --- | --- | --- |
| 抖音 | ✅ FLV（优先） | 取 HLS，房间没有 HLS 时提示改用外部播放器 |
| B站 | ✅ | 取 HLS（ts / fmp4） |
| 虎牙 | ✅ | 取 HLS |
| 斗鱼 | ✅ | ❌ 斗鱼只提供 FLV，菜单里不显示内置播放 |

- **APTV**：APTV 没有公开“播放指定地址”的链接格式。选 APTV 时脚本会复制该频道的播放地址并用 `aptv://` 打开 APTV；只要 APTV 里已经添加了同一个订阅，点同名频道即可。如果你知道可用的链接格式，可在设置里选“自定义”，用 `{url}`（编码后的地址）或 `{raw}`（原始地址）占位。
- **VLC** 使用 `vlc-x-callback://x-callback-url/stream?url=…`；**Infuse** 使用 `infuse://x-callback-url/play?url=…`。
- **内置播放**需要服务端版本包含 `/hls/` 路由（本仓库此次更新）。旧版服务端会返回 404，脚本会提示改用外部播放器。
- 内置播放时脚本先自己跟随服务端的 302 拿到平台 CDN 的 HTTPS 地址再交给 AVPlayer，因此服务地址是内网 `http://` 时也能播；302 无法携带 Referer 等请求头，个别 CDN 若要求请求头可能播不了，这时改用外部播放器。
- 关注列表只记住在订阅中出现过的频道。订阅里只有正在直播的频道，所以想长期关注的主播请先在“服务器与主播管理”里添加，开播后它就会出现在列表里，再点星标即可。
- 这些流程已在本地模拟服务端上验证；尚未在真机 Scripting 上验收，平台 HLS 能否直连播放取决于各 CDN。
